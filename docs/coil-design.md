# Coil / Magnetic System Design — MAC 5000 Rev. C

**Status:** Transparent calculator + constraint-first sweep are live. Results remain preliminary.

## Purpose

Quantify the power required to produce and sustain the magnetic field so we can close:

\[
P_{\rm net} = 500\,{\rm kW} - P_{\rm field} - P_{\rm pump} - P_{\rm cooling} - P_{\rm electronics} - \cdots
\]

## Ampere-turn requirement (idealized toroidal estimate)

At the preliminary design point:

- Target \(B \approx 0.48\,{\rm T}\)
- Mean radius \(r = 0.8\,{\rm m}\)

\[
NI = \frac{B \cdot 2\pi r}{\mu_0} \approx 1.93 \times 10^6\ {\rm A\!-\!turns}
\]

### Constraint-first evaluation

Every candidate is checked against hard limits **before** ranking:

| Limit                    | Default (editable)     |
|--------------------------|------------------------|
| Max current density      | 5 A/mm²                |
| Max copper temperature   | 90 °C                  |
| Max current per path     | 2 000 A                |
| Max copper volume        | 50 L                   |
| Max winding-window area  | 0.20 m² (placeholder)  |
| Cooling capacity         | 200 kW (placeholder)   |

Status flags assigned to every design:

- `PASS`
- `THERMAL_FAIL`
- `CURRENT_DENSITY_FAIL`
- `WINDOW_FAIL`
- `CONDUCTOR_CURRENT_FAIL`
- `MULTI_FAIL`

Only `PASS` designs are ranked (copper loss → copper volume → current per path).

The 1 000-turn / 100 mm² baseline is retained as a permanent regression case (~3.19 MW).

## Critical modeling rules already enforced

- Current density uses physical copper area only: \(J = I_{\rm path}/A_{\rm Cu}\)
- Packing factor is used solely for the winding-window constraint
- \(k_{\rm core}\) is a first-order sensitivity factor only (not a real magnetic circuit)
